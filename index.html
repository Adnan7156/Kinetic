Why hand-rolled?~180 lines

A canvas field like this one costs about the size of a long email. It has no dependencies to audit, no bundle to tree-shake, and it runs the same on a five-year-old phone as on a workstation — because you decide the node budget.

The rules are small: give every node a depth, move it, wrap it at the edges, draw links only to neighbours inside the radius, and let the pointer bend the field. Everything else is taste.

Drag node density to 200 and watch the frame budget readout climb. That number is the honest cost of prettiness.

Timing is the joke

The same 200 pixels travelled in 300 ms reads as responsive; at 1400 ms it reads as broken. Nothing about the movement changed except duration and easing. Most "animation polish" is really just choosing the right curve and the right clock.

Everything answers back

A control that gives no feedback feels dead even when it works. Ripples, state morphs, magnetic pull, cursor growth — these are not decoration, they are the interface telling you "I heard you." Aim for a response inside 100 ms and a settle inside 400 ms.

Layers, not decoration

Depth comes from things moving at different speeds, not from blur and shadows. This page stacks seven: wash, grid, canvas field, scan bar, content, grain, cursor. Move your pointer and the parallax offsets separate them for you.

Motion with manners

Vestibular disorders are common and full-screen movement can genuinely hurt. One media query buys you a lot of goodwill: honour it, keep the information, drop the travel. This page reads checking… right now.

prefers-reduced-motiontoggle the freeze

@media (prefers-reduced-motion: reduce) — collapse durations, kill infinite loops, remove grain and scan, and let reveals resolve instantly.

04 / Archive

The techniques, catalogued

Every card below is built with the same five ingredients: transform, opacity, easing, delay, and restraint.

A / 01

Particle field

A single canvas, a few hundred nodes, neighbour links inside a radius, and a pointer that bends the field. Runs on requestAnimationFrame and costs nothing to host.

B / 02

Kinetic type

Split the headline into spans, stagger the delay per character, and let a gradient sweep across the background-clip. Hover any letter on the title above.

C / 03

Sticky scroll rail

Pin a column, watch the other one scroll past, and swap the label with an IntersectionObserver.

D / 04

Verlet-ish physics

Integrate velocity, apply gravity, reflect at the walls with restitution. Squash on impact sells it.

E / 05

Magnetic UI

Translate a control toward the pointer by a fraction of the offset, snap it back on leave.

05 / Ship it

Live URL in about ninety seconds

GitHub Pages serves static files straight from a branch. One file is the easiest possible payload.

zsh — kinetic
  1. Save the fileEverything on this page lives in one index.html. Drop it in a folder.
  2. Make a repositoryName it username.github.io for a root URL, or anything else for a project URL.
  3. Push itRun the commands on the left. No build step, no package.json, nothing to install.
  4. Turn on PagesSettings → Pages → Source: Deploy from a branch → main / / (root).
  5. Wait a minuteYour site lands at https://username.github.io/repo/. Add a .nojekyll file if you later add folders starting with an underscore.

Keep asset paths relative (./assets/x.png), never root-absolute — project pages live in a subdirectory.
